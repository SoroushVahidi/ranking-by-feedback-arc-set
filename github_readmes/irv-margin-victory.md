# Computing the Margin of Victory in IRV Elections

Implementation of the algorithms from the paper "Computing the Margin of Victory in IRV Elections".

## Reference

- Paper (PDF): https://www.cs.cornell.edu/~tmagrino/papers/evt11.pdf

This repo provides code to compute or approximate the margin of victory (MoV) in Instant Runoff Voting (IRV) elections.

## What is in this repo

- Code implementing the MoV computation for IRV.
- Scripts to run on election data.
- Instructions to reproduce experiments (if applicable).

## How to run

1. Clone the repo and install dependencies.
2. Run the main program with an election instance (ballots in the format expected by the code).
3. See in-repo documentation for input format and options.
