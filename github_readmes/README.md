# GitHub READMEs for SoroushVahidi

This folder contains **ready-to-use README text** for each of your public GitHub repositories. Each file is meant to be copied into the corresponding repo as **README.md** so visitors get a clear explanation of what the repo does and how to use it.

## How to use

1. Open **INDEX.md** in this folder to see the mapping: repo name → filename.
2. Open the listed file and copy its full content.
3. In your GitHub repo (on the web or in a local clone), create or replace **README.md** with that content.
4. Commit and push.

**Exception:** For **ranking-by-feedback-arc-set**, the README is already at the root of the parent workspace (the "ranking by feedback arc set" repo). Copy that root **README.md** into the GitHub repo; do not use a file from this folder.

## What was preserved

- **Paper and reference links** that were already in your repos (e.g. arXiv, Springer, Cornell PDFs, FlyWire challenge, blog posts) are included in the new READMEs.
- **Citations** (e.g. for bfsbased_node_classification, Ranking_with_MWFAS, Fairness-Maximization, Design-exploration, IRV margin of victory, sudoku-example, weighted-minfas-codes) are kept.
- Repos that had no README now have a short, consistent explanation and usage section.
