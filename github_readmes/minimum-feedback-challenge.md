# Minimum Feedback Challenge

Codes and solutions for the **minimum feedback arc set (MFAS) challenge** at FlyWire Codex, by **Soroush Vahidi** and **Ioannis Koutis** (New Jersey Institute of Technology).

## Reference

- **Challenge:** https://codex.flywire.ai/app/mfas_challenge?dataset=fafb  
- This repository contains our implementations and solutions for the challenge (e.g. heuristics or exact methods for MFAS on the given dataset).

## What is in this repo

- Code to solve or approximate the MFAS problem on the challenge instances.
- Scripts to run on the fafb dataset (or other datasets as specified).
- Notes on the approach and results (if documented).

## How to run

1. Clone the repo and install dependencies (e.g. Python, C++, graph libraries).
2. Follow the instructions in the repo to fetch or prepare the challenge data.
3. Run the main script or solver and compare with the challenge evaluation (if applicable).
